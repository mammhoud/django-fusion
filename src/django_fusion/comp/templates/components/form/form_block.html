{% load i18n static wagtailcore_tags wagtailimages_tags %} {% comment %} django-fusion components/form/form_block.html — Wagtail StreamField form block ────────────────────────────────────────────────────────────────── Canonical form-block template used as the SINGLE source of truth for Wagtail StreamField form blocks across sites. Renders a dynamic form (HTMX + multipart) with per-field configuration, privacy consent, reCAPTCHA, submit button, and success/error templates. The caller is expected to pass: block : a Wagtail StreamField child-block instance (or a `as_form_block` synthesized equivalent). All `block.value.*` and `block.id` references dereference real attributes. page : the parent Wagtail page (used for hidden page_id). button_class: extra CSS classes for the submit button (optional). recaptcha_site_key: Google reCAPTCHA site key (optional). Override `{% block form_fields %}`, `{% block privacy_consent %}`, `{% block recaptcha %}`, `{% block submit_button %}`, `{% block success_template %}`, and `{% block error_template %}` to customize the rendered output for a specific site. USAGE — render from a Wagtail block: {% comp "components/form/form_block.html" with block=block page=page / %} {% endcomment %}
