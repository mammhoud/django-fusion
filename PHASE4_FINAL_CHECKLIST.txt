WORKFLOW ARCHITECTURE
================================================================================

REQUEST FLOW:
  User Request → Wagtail/Django Router → CoursesPage → get_context()
    ↓
  Extract Filters (GET params) → Apply Filtering & Pagination
    ↓
  get_filtered_courses() → get_paginated_context() → get_filter_options()
    ↓
  Build Full Context Dict → Render Template
    ↓
  HTML Response with HTMX Integration
    ↓
  User Interactions (AJAX) → HTMX Endpoints → Return Fragment Updates

FILTERING FLOW:
  Multiple GET parameters → Build filter dict → Query optimization
    ↓
  apply_difficulty() → apply_price_range() → apply_tags()
    ↓
  apply_search() → apply_sorting() → paginate()
    ↓
  Filter options with counts → Template rendering

ENROLLMENT FLOW:
  Enroll Button Click → HTMX GET Modal Form → User Submits
    ↓
  POST to create endpoint → CourseEnrollmentLead created
    ↓
  Success message displayed → Lead status = PENDING
