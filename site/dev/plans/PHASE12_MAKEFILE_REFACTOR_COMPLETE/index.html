    Linting & Code Quality¶

    make lint¶

    Run pylint on all Python code.

    make lint

    Purpose: Static code analysis and style checking.

    make format¶

    Format Python code with Black.

    make format

    Purpose: Auto-format code to Black standard.

    make typecheck¶

    Type checking with mypy.

    make typecheck

    Purpose: Verify type annotations and type safety.

    make lint-all¶

    Run both lint and typecheck.

    make lint-all

    Purpose: Complete code quality verification.

    Documentation & Info¶

    make docs¶

    Show available documentation.

    make docs

    Output: Lists all documentation files in docs/ directory.

    Cleanup & Utilities¶

    make clean¶

    Clean Python cache and build artifacts.

    make clean

    Removes: - __pycache__ directories - .pytest_cache directories - .mypy_cache directories - dist/ and build/ directories - *.egg-info directories

    make show-targets¶

    List all available make targets.

    make show-targets

    Output: Alphabetically sorted list of all targets.

    make show-vars¶

    Print all Makefile variables and their values.

    make show-vars

    Displays: - WEBSITE, SITE, TEST_WEBSITE - MANAGE, DOCKER_SERVICE - DOCKER_PROJECT_PATH, COMPOSE_FILE - PYTHON, LOG_DIR, SERVER_TYPE

    make show-config¶

    Show complete configuration (vars + derived paths).

    make show-config

    Equivalent to: make show-vars + additional derived information.
