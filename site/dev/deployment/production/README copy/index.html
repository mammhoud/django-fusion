    Common Tasks¶

    Deploy All Sites¶

    cd /root/site/websites/assets
npm run build:all
npm run collectstatic
cd ..
docker-compose up -d
    See: QUICK_START.md

    Check System Status¶

    docker compose ps
docker compose logs -f

    Run Tests¶

    bash run_full_test_suite.sh
    See: TEST_PLAN.md
