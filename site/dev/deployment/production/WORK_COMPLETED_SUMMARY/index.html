    Key Learnings¶

    1. Fixture Format Compatibility
    2. Always verify fixture models exist before loading
    3. Old fixture data from different Django/Wagtail versions may be incompatible

    4. Use management commands when available for data migration

    5. Content Type References

    6. Django content types can change between app versions
    7. FK constraints on content types can prevent fixture loading

    8. Solution: Filter fixtures or use API-based migration

    9. Multilingual Setup

    10. Wagtail-localize handles translations well
    11. Locales need to be created before pages

    12. Page tree is per-locale, not shared

    13. Infrastructure as Code

    14. Docker Compose works well for complex setups
    15. Service naming matters (normalized names without suffixes)
    16. Health checks should use proper hostnames
