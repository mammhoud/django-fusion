# Assets Directory

This directory contains all static and media files for the structa.cloud website.

## Directory Structure

```
assets/
├── bundles/           # Webpack-generated bundles (JS, CSS, fonts, images)
│   ├── css/          # Compiled CSS files
│   ├── js/           # Compiled JavaScript files
│   ├── fonts/        # Web fonts
│   ├── images/       # Optimized images
│   └── chunk/        # Code-split chunks
├── fixtures/          # JSON fixtures for initial data
├── locale/            # Translation files (i18n)
├── media/             # User-uploaded media files
├── templates/         # Custom HTML templates
└── .well-known/       # Security and verification files
```

## Build Commands

### Full Asset Build (Webpack + Collectstatic)

```bash
# From project root
python manage.py build_assets

# Production build (default)
python manage.py build_assets --production

# Development build
python manage.py build_assets --development

# Watch mode for development
python manage.py build_assets --watch
```

### Webpack Only

```bash
# Production build
npm run build:prod

# Development build
npm run build:dev

# Watch mode
npm run watch

# Development server with hot reload
npm run dev
```

### Django Collectstatic Only

```bash
python manage.py collectstatic --no-input
```

### Clean Build

```bash
# Clean bundles and rebuild
python manage.py build_assets --clean

# Or manually
npm run clean
python manage.py build_assets
```

## Translation Commands

```bash
# Create message files for a language
django-admin makemessages -l ar
django-admin makemessages -l en
django-admin makemessages -l fr
django-admin makemessages -l de

# Compile translations
django-admin compilemessages
```

## Notes

- **bundles/**: Generated by webpack, do not edit manually
- **staticfiles/**: Generated by `collectstatic`, do not edit manually
- **media/**: User uploads, managed by Django
- **fixtures/**: Initial data for database seeding
- **locale/**: Translation files (.po, .mo)

## Configuration

The asset paths are configured in:
- `www/configs/base/assets.py` - Django static files settings
- `webpack/main.config.js` - Webpack configuration
- `package.json` - NPM scripts and dependencies
