## What is django-fusion?

django-fusion is a Django testing framework providing:
- Property-based testing utilities
- Test fixtures and factories
- Assertion helpers for Django models and views
- Integration test utilities

## Installation

```bash
pip install git+https://github.com/mammhoud/django-fusion.git@main
# or with uv
uv add "django-fusion @ git+https://github.com/mammhoud/django-fusion.git@main"
```
