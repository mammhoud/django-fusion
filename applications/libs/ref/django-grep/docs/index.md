# Django-grep Documentation Index

django-grep is a Django testing framework and utilities library.

## Table of Contents

- [Usage Guide](usage.md)
- [Examples](examples.md)
- [Utilities](utils.md)
- [Product Overview](product.md)

## Key Features

- **Testing utilities**: Helpers for writing Django tests with less boilerplate
- **Property-based testing**: Integration with hypothesis for Django models
- **Fixtures**: Reusable test data factories
- **Assertions**: Django-specific assertion helpers

## Getting Started

1. Install: `pip install django-grep`
2. Add `django_grep` to `INSTALLED_APPS`
3. Import test utilities from `django_grep.testing`

See [usage.md](usage.md) for detailed instructions.
