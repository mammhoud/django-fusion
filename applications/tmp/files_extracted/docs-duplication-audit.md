## Reading this table

1. **`docs/websites/<site>/`is already the canonical location** for ctc-research, lms, vresume, cypercloud, and crm — it's the largest/most complete in every case, and it's the exact path `AGENTS.md`'s own "Site AGENTS.md and PROMPTS.md Cross-Reference" table already declares canonical (`docs/websites/ctc-research/index.md`, etc.). Don't invent a new path — consolidate into this one.
2. **`docs/libs/<lib>/`is already the canonical location** for the two lib docs mirrors (django-fusion, ceptor-ai) — but see the companion `django-fusion-execution-plan.md` and the main `structa-cloud-execution-plan.md`: the real source of truth for these two libs should be their own standalone repos (`mammhoud/django-fusion`, `mammhoud/ceptor-ai`), with `docs/libs/<lib>/` treated as a synced *copy*, not a second original.
3. **Several "locations" are empty (0 KB) directories** — `docs/ctc-research/`, `docs/structa-cloud/`, `docs/django-fusion/`, `docs/ceptor-ai/` are stubs with nothing in them. These are the cheapest possible deletions: no content to preserve, no diff needed, just remove the empty directory.
4. **The four architecture PNGs total ~11.7 MB** (`structa.cloud.png` 2.1M, `django-fusion.png` 3.2M, `django-osoul.png` 3.2M, plus `django-grep.png`/`django-rseal.png` from the earlier review, not shown here since they don't match a current topic keyword — meaning they may be fully orphaned). These belong out of git history weight — see Phase 2 of the execution plan.
5. **`auth-register` is the cleanest case**: three root-level files, no directories, all small, already scoped in the earlier enhancement doc §5.
