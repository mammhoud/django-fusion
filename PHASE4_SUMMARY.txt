================================================================================
COURSE SYSTEM FLOW
================================================================================

1. USER VISITS /courses/
   └─ Wagtail routes to CoursesPage instance

2. COURSESPAGE.GET_CONTEXT() PROCESSES:
   ├─ Extracts GET parameters (filters, search, sort, page)
   ├─ Calls get_filtered_courses(**filters)
   ├─ Calls get_paginated_context(courses, page)
   ├─ Calls get_filter_options()
   └─ Returns full context

3. TEMPLATE RENDERS:
   ├─ Search bar with HTMX integration
   ├─ Filter sidebar with checkboxes
   ├─ Course cards in grid/list view
   ├─ Pagination links
   └─ HTMX buttons for enrollment/wishlist

4. USER INTERACTIONS (AJAX/HTMX):
   ├─ Filter changes → GET /courses/?filters
   ├─ Search → GET /courses/?q=query
   ├─ Pagination → GET /courses/?page=N
   ├─ Enroll → GET /learning/enrollment/form/{id}/ → POST /create/
   └─ Wishlist → POST /learning/wishlist/toggle/{id}/

================================================================================
KEY MODELS & RELATIONSHIPS
================================================================================

COURSE (Main Model):
  ├─ FK: instructor (User)
  ├─ FK: image (wagtailimages.Image)
  ├─ M2M: specializations (Specialization)
  ├─ M2M: categories (CourseCategory)
  ├─ M2M: tags (CourseTag)
  └─ Reverse: modules (Module)
                enrollment_leads (CourseEnrollmentLead)
                reviews (Review)

COURSESPAGE (Wagtail):
  └─ M2M: selected_courses (Course)

COURSEENROLLMENTLEAD (Lead Tracking):
  └─ FK: course (Course)

SPECIALIZATION (Category):
  └─ M2M: courses (Course)

MODULE (Course Structure):
  ├─ FK: course (Course)
  └─ Reverse: lessons (Lesson)

================================================================================
FILTERING CAPABILITIES
================================================================================

SEARCH:
  ?q=python              → Full-text search in title/description

DIFFICULTY:
  ?difficulty=beginner   → Filter by difficulty level

PRICE RANGE:
  ?price_min=50&price_max=200 → Filter by price range

TAGS:
  ?tags=1&tags=2         → Filter by multiple tags (IDs)

SORTING:
  ?sort=-created_at      → Newest First (default)
  ?sort=title            → Alphabetical
  ?sort=-rating          → Highest Rated
  ?sort=price            → Price Low-High
  ?sort=-price           → Price High-Low

PAGINATION:
  ?page=2                → Second page (12 courses/page)

COMBINED EXAMPLE:
  /courses/?q=python&difficulty=intermediate&price_max=100&sort=price&page=1

VIEWS & ENDPOINTS
================================================================================

WAGTAIL PAGE:
  GET  /courses/                    → CoursesPage (main catalog)

DJANGO VIEWS:
  GET  /learning/course/{slug}/     → FrontCourseDetailView (detail page)
  GET  /learning/course/{slug}/lesson/{id}/ → CourseWatchView (lesson)
  GET  /learning/course/{slug}/continue/    → CourseContinueView (resume)
  POST /learning/enroll/{slug}/             → EnrollView (enrollment page)
  
AJAX/HTMX ENDPOINTS:
  GET  /learning/enrollment/form/{course_id}/    → Enrollment modal form
  POST /learning/enrollment/create/{course_id}/  → Create enrollment lead
  POST /learning/wishlist/toggle/{course_id}/    → Toggle wishlist

API ENDPOINTS:
  GET  /learning/api/courses/search/?q=query&difficulty=beginner → JSON
