# 💊 Fusion Assets Health — Static Asset Pipeline

This guide is the monorepo entry point for the shared asset and health contracts. The detailed library reference is [`DF-017`](/docs/en/libs/django-fusion/17-integration-modes).

---

## Where Code Belongs

- `libs/django-fusion/src/django_fusion/core/assets/` — canonical asset JSON views and URL patterns
- `libs/django-fusion/src/django_fusion/templatetags/fusion_assets.py` — `{% asset %}` template tag
- `projects/*/assets/` — project-specific SCSS, compiled CSS, images, media
- `projects/*/backend/assets/staticfiles/` — collected static output (gitignored)

---

## Asset Pipeline Overview

```
Source SCSS/JS (projects/*/assets/, libs/django-fusion/assets/)
    │
    ▼
Compile (make css / npm run build)
    │
    ▼
Manifest JSON (assets/static/bundles/bundles.json)
    │
    ▼
Collectstatic (python manage.py collectstatic)
    │
    ▼
Staticfiles Volume → Shared Proxy (Nginx) → CDN / Browser
```

## Health Checks

### 1. Bundle Manifest Validation

```bash
# Validate bundles.json exists and is parseable
cat projects/structa.cloud/backend/assets/static/bundles/bundles.json | jq .

# Expected keys: main.css, main.js, vendor.css, vendor.js, fusion.css
```

### 2. CSS Health

```bash
# Check compiled CSS size
wc -c projects/structa.cloud/backend/assets/staticfiles/css/fusion.css

# Validate no duplicate selectors (rough check)
awk '/\{/{print}' projects/structa.cloud/backend/assets/staticfiles/css/fusion.css | sort | uniq -d
```

### 3. JS Bundle Health

```bash
# Check bundle sizes
ls -lh projects/structa.cloud/frontend/dist/assets/

# Source map verification
file projects/structa.cloud/frontend/dist/assets/*.js.map
```

### 4. django-fusion Asset Views

```bash
# Test asset manifest endpoint
curl -s https://structa.cloud/api/assets/manifest/ | jq .

# Test individual asset
curl -s https://structa.cloud/static/css/fusion.css | head -20
```


### django-fusion Asset Manifest

The `bundles.json` is generated by `django-fusion` during `collectstatic`:

```json
{
  "fusion.css": "/static/css/fusion.css?v=abc123",
  "main.js": "/static/js/main.abc123.js",
  "vendor.js": "/static/js/vendor.def456.js"
}
```

Used by `{% asset "main.js" %}` template tag for cache-busted URLs.

## Common Issues & Fixes

| Symptom | Cause | Fix |
|---------|-------|-----|
| 404 on `/static/css/fusion.css` | `collectstatic` not run | `docker exec <container> python manage.py collectstatic --noinput` |
| Stale CSS in browser | Cache busting failed | Check `bundles.json` has hash; rebuild frontend |
| Duplicate CSS selectors | Multiple `make css` runs | Clean `assets/static/css/` before rebuild |
| Missing `fusion.css` in manifest | `django-fusion` not in `INSTALLED_APPS` | Add `'django_fusion'` to `INSTALLED_APPS` |
| Asset hash mismatch | Frontend + backend out of sync | Rebuild frontend → `collectstatic` → deploy |

## ## Remarks & Notes

- `fusion.css` is the single compiled design-system stylesheet — all projects share it.
- `bundles.json` is the source of truth for cache-busted URLs; never edit manually.
- Asset health checks run in `make probe-health` and CI.
- Breaking changes to asset pipeline require version bump in `django-fusion`.
