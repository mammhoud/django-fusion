> والقرارات المبنية على البيانات عبر منتجات Structa Cloud

## المسؤوليات الأساسية

### 1. التحقق من الادعاءات المدعومة بالأدلة

**المصدر:** `docs/plans/marketing-claims.md`
**القاعدة:** الادعاءات الموضوعية تتطلب أدلة قبل النشر

| مستوى الدليل | المعنى | قاعدة النشر |
|-------------|---------|------------------|
| قدرة | المنتج مصمم/منفَّذ ليفعل شيئاً | قل «يدعم/يتضمن» فقط عند وجود دليل إصدار |
| أدلة تجربة | لوحظ في تجربة داخلية/عميل مسماة | أدرج النطاق والتاريخ والعينة والحدود |
| قياس منشور | معيار قابل للتكرار أو مقياس تشغيلي | أدرج الطريقة والأساس والبيئة وتاريخ المراجعة |
| ادعاء منظَّم | نتيجة امتثال/قانونية | يلزم مراجعة مختص محلي/قانوني |

### 2. لغة التموضع المعتمدة

| الادعاء | الصياغة الآمنة الآن |
|-------|-------------------|
| العربية أولاً | «مصمم لسير عمل المطاعم العربية والثنائية اللغة.» |
| العمل دون اتصال أولاً | «استمر في العمليات الأساسية أثناء الانقطاعات وسوِّ لاحقاً.» |
| KDS | «وجّه ورتّب تذاكر المطبخ عبر المحطات.» |
| تعدد الفروع | «أدر عمليات الفروع من عرض تحكم مشترك.» |
| الولاء | «ابنِ برامج زيارات متكررة بدفتر مكافآت قابل للتدقيق.» |
| وصول API | «تكامل عبر API مُصدَّر دون وصول مباشر لقاعدة البيانات.» |
| من المحلي إلى السحابي | «ابدأ محلياً وانتقل إلى خدمات سحابية مُدارة عند الجاهزية.» |

### 3. ادعاءات تتطلب أدلة قبل الاستخدام

- «ضمان الجاهزية» أو أي نسبة توفر رقمية
- «أسرع بـ X%» في الدفع/KDS/التحضير
- «متوافق كلياً» مع ZATCA أو هيئة الضرائب الإماراتية أو VAT أو أي جهة أخرى
- «يوفر X%» أو «يرفع الإيرادات/الاحتفاظ بـ X%»
- «رائد السوق»، «الأفضل»، «الوحيد» أو مقارنات المنافسين
- «جاهز للإنتاج» لميزة ما زالت مخططة أو في الترحيل
- وعود تسعير/هامش غير مدققة مقابل تكاليف الدعم والاستضافة والدفع والتخزين
