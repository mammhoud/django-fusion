## السلاسل العمودية النشطة (بالترتيب الأولوي)

### 1. سلسلة إصدارات Formint — P0

| الإصدار | الحالة | البوابة التالية |
|---------|--------|-----------|
| المجتمعي (Community) | مكتمل | — |
| القياسي (Standard) | مكتمل | — |
| الاحترافي (Professional) | جارٍ | مزامنة الواجهة الخلفية والفوترة |
| السحابي (Cloud) | مخطط | SaaS متعدد المستأجرين |
| العميل (Client) | مكتمل | تكامل Cloud API |

### 2. Precis Landing — P0

موقع تسويقي حيّ (نسخة قديمة تُخدم) — العمل الجديد في المنتج الموحّد أدناه.

### 3. Precis الموحّد (نظام التعلّم) — P1

**المسار:** `projects/structa.cloud/` (دمج نظام التعلّم + صفحة الهبوط)
**المجالات:** بناء الواجهة، بوابات النشر، تكامل CMS، كتالوج SEO

### 4. مركز CTC البحثي — نشط

**المجالات:** تدقيق المحتوى، كتالوجات متعددة اللغات (es/sv/pt-br)، وكيل الوسائط،
تكافؤ البريد، بوابات النشر

### 5. Syntara (Cypercloud) — نشط

**المنتجات:** دردشة AI، اكتشاف القوالب، تخصيص الكود، ردود متدفقة
**يعمل محلياً:** Ollama · **متبقٍ:** مفاتيح مزوّدي الاتصال الحيّ

### 6. Loop-CRM — نشط (الدمج مكتمل على مستوى الميزات)

**المعالم:** العزل والمصادقة → CRUD بنطاق المستأجر → القنوات والمحوّلات →
allauth → دفتر التمويل → مركز AI واللغة → الفوترة وصفحة الهبوط
**البوابات المتبقية تشغيلية لا برمجية:** بيانات مزوّدي OAuth الحيّة، وتحصين
الزمن الفعلي عند النشر، والتحقق من حالة العرض على الخادم.

### 7. django-fusion (الإطار المشترك) — P2

المهام وMCP · تعزيز LLM & AI · تعزيز Webpack · واجهات المحلّل والهيكل والأصول
