# Asmaa — تطوير البيانات

> **الهدف:** أن يصبح كل رقم يكرّره الفريق رقماً واحداً، محسوباً مرة واحدة.
> **يتحقّق منه:** Moustafa (الادعاءات)، Mahmoud (الإيراد) · **المراجعة:** أسبوعية

## المهام

| # | المهمة | يكتمل عندما | المتحقِّق |
|---|---|---|---|
| 1 | تعريفات المقاييس | صياغة واحدة وحساب واحد لكل مقياس | Moustafa |
| 2 | تحديث المقاييس الأسبوعي + ملاحظة الشذوذ | الأرقام محدَّثة؛ وأي شيء غريب مُسمّى | Mahmoud |
| 3 | سجل دليل لكل ادعاء نشط | ادعاء ← مصدر ← تاريخ ← ثقة | Moustafa |
| 4 | تقرير نتيجة التجربة | النتيجة، وحجم العيّنة، وما لا تُثبته | Moustafa |
| 5 | أسطح التقارير مع Yahia | اللوحة تُظهر التعريف، لا القيمة فقط | Yahia |
| 6 | تدقيق أدلّة الادعاءات ربع السنوي | كل ادعاء عام لا يزال مسنوداً أو مُعلَّماً | Mahmoud |

## يعمل مع

| الفرد | في |
|---|---|
| Moustafa — مدير منتج + تسويق | تعريفات المقاييس، أدلّة الادعاءات، تقارير الحملات |
| Mahmoud — مدير عام | مقاييس الإيراد، المراجعة الأسبوعية للأرقام |
| Yahia — واجهات أمامية + تجربة | أسطح التقارير واللوحات |
| Dariia — مساهم | نصوص التقارير والتوثيق |
