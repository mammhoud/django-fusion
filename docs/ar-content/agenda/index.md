## 📋 إرشادات الاستخدام

1. **ابدأ بـ `MAIN.md`** — يشرح كيف يعمل نظام الجدول وكيف يرتبط كل شيء
2. **استخدم الأداة المناسبة للوظيفة:**
   - تتبع ميزة؟ → `feature-tracking.md`
   - تشغيل سبرينت؟ → `task-tracking.md` + `meeting-agenda.md`
   - نشر شيء worth ذكر؟ → `case-studies.md` (اكتب دراسة حالة مع مخطط mermaid)

3. **سجّل القرارات في `team-notes.md`** — حتى القرارات الصغيرة matter مع الوقت
