# 💰 الأسعار والعروض والخدمات — 🔒 خاصة

> دفتر أسعار داخلي. نموذج تغليف واحد لكل المنتجات: **ترخيص + استضافة مُدارة +
> إعداد + دعم**، مع التخصيص بعلامة بيضاء كعرض إضافي.

## 1. نموذج التغليف

| الطبقة | الوصف | الفوترة |
|--------|-------|---------|
| الترخيص | حقوق المنتج ذاتية الاستضافة + التحديثات | دفعة واحدة + نسبة دعم سنوية |
| المُدارة | الحزمة المنشورة (DB، وسائط، وكيل، مهام، نسخ، مراقبة) | شهرياً لكل موقع |
| الإعداد | النشر، DNS/SSL، ترحيل المحتوى، العلامة | دفعة مشروع واحدة |
| الدعم | L1 دردشة/بريد + L2 ترقيات | ضمن المُدارة |
| التخصيص | علامة بيضاء + إعدادات | رسوم إعداد + اشتراك اختياري |

## 3. العروض وسياسة الخصم

- **عرض الإطلاق:** أول 3 مقاعد بسعر التأسيس (شهر مجاني أو 20% لمدة 6 أشهر).
- **دفع سنوي:** شهران مجاناً على أي طبقة مُدارة.
- **خصم الحزم:** 10% عند ترخيص منتجين أو أكثر.
- **الإحالة:** شهر رصيد لكل عميل مُحال.
- لا تُخفض تحت التكلفة: الحد الأدنى = تكلفة الاستضافة × 3 + دعم 30 دقيقة.

## 4. الخدمات (التخصيصات الجانبية)

| الخدمة | الوصف |
|--------|-------|
| تخصيص بعلامة بيضاء | نظام تصميم باسم العميل، نطاق، ألوان عبر `configs/theme.yml` |
| ترحيل المحتوى | استيراد الدورات والمتعلمين من أنظمة قديمة (CSV/موقع قديم) |
| إعداد عربي/RTL | موقع عربي كامل مع تكافؤ RTL ومحتوى عربي |
| البريد والمصادقة | بريد معاملات بعلامة العميل، دخول اجتماعي، MFA |
| التكاملات | مدفوعات (Stripe)، نشرة (Mailchimp/Brevo)، تحليلات |
| التدريب | جولة للمحررين (عربي/إنجليزي) |
| تطوير مخصص (مرحلة 2) | خارج الإعدادات والتخصيص — عقد منفصل |

## 5. منطق الحزم

- **طبقة المُدارة تحمل الإيراد الشهري**؛ الترخيص والإعداد يغطيان تكلفة التسليم.
- العلامة البيضاء هي عرض البيع الإضافي الذي يحوّل النشر إلى علامة.
- عملاء «بدون أي شيء» (انظر `sales.md`) يبدأون دائماً من المُدارة — وليس
  الترخيص فقط — لأنهم بلا خادم أو موظفي تقنية.
