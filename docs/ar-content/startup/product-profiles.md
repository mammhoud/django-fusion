## 1. 🤝 Loop-CRM — نظام التشغيل التجاري 🟢

> **المسار:** `projects/loop-crm/` · **الاستراتيجية:** [`/docs/en/startup/loop-crm`](/docs/en/startup/loop-crm)

Loop CRM نظام تشغيل حديث للمنظمات. على عكس أنظمة CRM التقليدية، يوحّد Loop CRM
المبيعات والتسويق والدعم والمشاريع والمالية والموارد البشرية والتحليلات وأتمتة
الذكاء الاصطناعي في منصة واحدة.

**الرؤية:** منصة واحدة لإدارة دورة حياة العميل والعمليات التجارية بالكامل.
**العملاء المستهدفون:** الشركات الصغيرة والمتوسطة والمؤسسات والوكالات
والمنظمات التعليمية والصحية.

### الوحدات

| الوحدة | الميزات الأساسية |
|--------|------------------|
| المبيعات | العملاء المحتملون، جهات الاتصال، الحسابات، الفرص، خطوط الأنابيب، عروض الأسعار، العقود، الأنشطة |
| التسويق | الحملات، النشر الاجتماعي، التسويق بالبريد، أتمتة التسويق، التحليلات |
| نجاح العملاء | التجديدات، صحة العملاء، تتبع دورة الحياة |
| الدعم | التذاكر، قاعدة المعرفة، الدردشة المباشرة، تتبع SLA |
| المشاريع | المهام، كانبان، جداول الوقت، المعالم |
| الموارد البشرية | الموظفون، الحضور، الرواتب، التوظيف |
| المالية | الفواتير، المصروفات، المدفوعات، التقارير |
| الذكاء الاصطناعي | وكيل المبيعات، وكيل التسويق، وكيل الدعم، وكيل المعرفة |

### التكاملات

WhatsApp · Telegram · البريد الإلكتروني · Stripe · Paymob · Zoom · Google

## 2. 🎓 منصة Precis — منصة التجربة الرقمية الموحدة

> **المسار:** `projects/structa.cloud/` (نظام تعلم + هبوط منشور) ·
> **الاستراتيجية:** [`/docs/en/startup/precis`](/docs/en/startup/precis)

Precis منصة موحدة تتيح للمنظمات بناء المواقع وإدارة المحتوى وإنشاء بوابات
التعلم وتشغيل مراكز البحث وتوليد التطبيقات وإطلاق منتجات SaaS وإدارة المعرفة
وتشغيل الأعمال الرقمية — من منظومة واحدة. **الرؤية:** منصة واحدة، حلول متعددة،
إمكانيات غير محدودة.

### الخدمات المشتركة

المصادقة (SSO، إدارة مساحة العمل، الفرق) · الأمان (RBAC، الصلاحيات، سجلات
التدقيق) · خدمات المنصة (الإشعارات، الفوترة، الاشتراكات، التكاملات) · واجهات
برمجة التطبيقات (REST, GraphQL, Webhooks).

> **تدقيق الواقع:** اليوم المنصة هي **نظام التعلم + واجهة الهبوط** المدمجة في
> `precis-main`. وحدات CMS/Builder/Research رؤيوية وموثّقة أدناه.

## 3. 🎨 Precis CMS — إدارة المحتوى المؤسسي 🔴 رؤيوي

- **المحتوى:** الصفحات والمقالات والمدونات والتوثيق وقاعدة المعرفة؛ محرر بصري،
  محتوى منظم، إصدارات، مسودات
- **النشر:** الجدولة، سير عمل المراجعة، الموافقات
- **المؤسسي:** متعدد المواقع، متعدد اللغات، متعدد المستأجرين
- **واجهات برمجة:** REST, GraphQL
- **الذكاء الاصطناعي:** كاتب ذكاء اصطناعي، اقتراحات SEO، ملخصات المحتوى

> أقرب كود منشور هو نظام محتوى Wagtail في `precis-main` و`precis-ctc` — منتج
> CMS المستقل غير موجود بعد.

## 4. 🛠️ Precis Builder — منصة توليد المواقع والتطبيقات 🔴 رؤيوي

- **الوحدات:** منشئ المواقع (الشركات/المنتجات/التسويق)، منشئ الصفحات الهبوطية
  (الحملات/توليد العملاء/الفعاليات)، منشئ البوابات (العملاء/الموظفون/البحث)،
  منشئ التطبيقات (الأدوات الداخلية/لوحات المعلومات/واجهات CRM)
- **الميزات:** بناء بالسحب والإفلات، نظام سمات، مكوّنات قابلة لإعادة الاستخدام،
  رموز تصميم، توليد بالذكاء الاصطناعي، نماذج ديناميكية، تحسين SEO

> رؤيوي فقط — لا يوجد منتج منشئ في المستودع.

## 6. 🔬 Precis Research — منصة البحث والنشر الأكاديمي 🟢 بذرة / 🔴 منصة

> مدعومة بـ CTC Research · **المسار:** `projects/precis/precis-ctc/` ·
> **الاستراتيجية:** [`/docs/en/startup/precis-ctc`](/docs/en/startup/precis-ctc)

دورة حياة البحث الكاملة من توليد الفكرة إلى النشر: الفكرة ← مراجعة الأدبيات ←
تصميم البحث ← جمع البيانات ← التحليل ← الكتابة ← التقديم ← النشر.

- **مساحة عمل البحث:** المشاريع والفرق والمهام
- **مراجعة الأدبيات:** المراجع والمكتبات وإدارة المصادر
- **الكتابة العلمية:** منشئ المخطوطات والقوالب والاستشهادات
- **مركز النشر:** إيجاد المجلات وتتبع التقديم ومراقبة النشر
- **مركز الإحصاء:** التحليل والتصور والتقارير
- **مساعد بحث بالذكاء الاصطناعي:** الملخصات والتوصيات وتحليل الأدبيات
- **مركز التعلم:** الدورات وورش العمل والشهادات

> **تدقيق الواقع:** CTC Research (ctc-research.com) هو الموقع المؤسسي المنشور
> مع خط نشر وتكافؤ EN/AR. منصة البحث الأوسع للمؤسسات المتعددة رؤيوية.

## 7. 🧩 django-fusion — إطار التطوير السريع للمنصات 🟢

> **المسار:** `libs/django-fusion/` · **دليل الحزمة:** [`/docs/en/libs/django-fusion`](/docs/en/libs/django-fusion)

أساس التقنية الذي يحرّك منتجات Structa Cloud. يوفر لبنات بناء قابلة لإعادة
الاستخدام تسرّع التطوير وتضمن الاتساق عبر جميع المنصات.

### الحزم — التخطيط الفعلي (`src/django_fusion/`)

| الوحدة الفعلية | ماذا توفر |
|----------------|-----------|
| `comp` | نظام المكوّنات `{% comp %}` |
| `fragments` | أجزاء HTMX والجداول والنماذج |
| `routes` / `services` | توجيه Viewset/ModelViewset وطبقة الخدمات |
| `core` / `contrib` | النماذج والأدوات الأساسية |
| `config` | تدرج إعدادات متعدد الطبقات (`config.project`) |
| `mcp` | خادم أدوات MCP |
| `tasks` | واجهة برمجة المهام الخلفية (مدعومة بـ Dramatiq) |
| `models` / `assets` / `designer` / `plugins` | النماذج الأساسية وخط الأصول والمساعدات والإضافات |

> **ملاحظة تصحيحية:** بعض عروض الشرائح الخارجية تسرد حزماً طموحة — "Fusion
> Core / Identity / CMS / API / Builder / Workflow / Analytics / AI /
> Notifications / Tenants" كتطبيقات `fusion.*`. **هذه الحزمة غير موجودة.** الإطار
> هو تخطيط `django_fusion` داخل المستودع أعلاه. استخدم أسماء الوحدات الفعلية في
> أي مادة عامة.
