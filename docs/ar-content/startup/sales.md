## 1. متطلبات البيع (قائمة الجاهزية)

قبل بيع أي حزمة يجب توفر كل البنود:

- [ ] الحزمة والسعر محددان (`pricing.md`) ويوجد قالب عرض سعر.
- [ ] موقع تجريبي حي على بنية الإنتاج.
- [ ] `make redeploy` يعمل من البداية إلى النهاية (حلقة تسليم مُنتجة).
- [ ] النسخ الاحتياطي والاستعادة مُتحققان للحزمة المُدارة.
- [ ] مستويات الدعم وأوقات الاستجابة محددة.
- [ ] وثائق العميل موجودة (عربي/إنجليزي).
- [ ] كل ادعاء تسويقي مدعوم بأدلة (`marketing-claims.md`).

## 2. قائمة فحص العرض والعقد

| البند | التفاصيل |
|-------|----------|
| النطاق | المخرجات الدقيقة من الحزمة + بنود إضافية |
| السعر والفوترة | دفعة واحدة + شهري، العملة، سنوي/شهري |
| المدة | حد أدنى (12 شهراً مُداراً)، التجديد |
| الملكية والبيانات | المحتوى/البيانات ملك العميل؛ البرنامج ترخيص وخدمة |
| الاستضافة | أين تعمل (بنيتنا المُدارة أو خادم العميل)، SLA للنسخ |
| الدعم | القنوات، الساعات (عربي/إنجليزي)، أهداف الاستجابة، الاستثناءات |
| الترحيل | ماذا نستورد، المصادر، من يتحقق |
| التخصيص | ما التخصيص المشمول؛ التطوير الإضافي عقد منفصل |
| الإنهاء | الإشعار، تصدير كامل للبيانات، جدول الحذف |

## 3. العملاء من الصفر (بدون مرافق/أجهزة)

عملاء يبدأون **بلا شيء** — لا نطاق ولا بريد ولا خادم ولا موظفي تقنية. الرحلة
كلها ضمن **المُدارة** (وليس الترخيص فقط):

| الخطوة | ما نفعله نحن | ما يفعله العميل |
|--------|-------------|-----------------|
| 1. الاكتشاف | استبيان: النشاط، المحتوى، العلامة، اللغات | إجابة نموذج (30 دقيقة) |
| 2. النطاق والبريد | شراء/نقل النطاق + إعداد صندوق البريد | الموافقة على التكاليف |
| 3. البنية | تجهيز الحزمة المُدارة (DB، وكيل، TLS، وسائط) | لا شيء |
| 4. البناء | نشر الموقع، علامة بيضاء، ترحيل المحتوى | إرسال الملفات والعلامة |
| 5. التدريب | جولة إدارية + أوراق مختصرة (عربي/إنجليزي) | حضور 1–2 جلسة |
| 6. التسليم | بيانات الدخول، دليل التشغيل، قناة الدعم | استلام |

**مخرجات التسليم:** رابط لوحة الإدارة + بيانات الدخول، روابط الموقع، دليل
النسخ/الاستعادة، قناة الدعم، جدول الفواتير.

## 4. قائمة فحص التسليم

- [ ] الموقع سليم: `/health/`، `/apis/pages/`، `/static/`، `/media/`.
- [ ] شهادة TLS صادرة + تحويلات (www، http→https).
- [ ] نسخ احتياطي مُتحقق (استعادة مُختبَرة مرة في staging).
- [ ] مراقبة وتسجيل أخطاء فعّالان.
- [ ] سُلِّمت بيانات العميل ودُوِّر كلمة مرور الإدارة.
- [ ] وثائق العميل سُلِّمت (عربي/إنجليزي).
- [ ] فُتحت تذكرة دعم للعميل؛ بدأت ساعة SLA.
