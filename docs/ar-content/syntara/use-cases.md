# Syntara — حالات الاستخدام

## 1. مساعد الكود المدعوم بالذكاء الاصطناعي (`code-assistant`)

- **الغرض:** واجهة دردشة لتوليد الكود وتصحيح الأخطاء وإعادة الهيكلة
- **الميزات الأساسية:** استجابات متدفّقة (SSE)، دعم نماذج متعددة (Ollama/OpenAI/Claude/Gemini)، محرر كود Monaco
- **التخصيص:** أضِف خلفيات ذكاء اصطناعي جديدة عبر تكوين وكيل Ceptor-AI

## 2. اكتشاف القوالب وتخصيصها (`template-discovery`)

- **الغرض:** تصفّح وتعديل قوالب Django/Wagtail عبر مواقع متعددة
- **الميزات الأساسية:** مسح متعدد المواقع (CTC Research، LMS، VResume)، عرض تدرّج القوالب، معاينة المقاطع/الكتل
- **التخصيص:** أضِف مواقع جديدة إلى `CUSTOMIZER_APPS` في settings.py

## 3. تنفيذ أدوات MCP (`mcp-tools`)

- **الغرض:** تنفيذ أدوات بروتوكول سياق النموذج (MCP) عبر وكلاء الذكاء الاصطناعي
- **الميزات الأساسية:** مطالبات استدعاء الأدوات، استجابات JSON منظَّمة، تكوين وكيل متعدد الخلفيات
- **التخصيص:** أضِف أدوات MCP جديدة في مكتبة `ceptor-ai`

## 4. تطوير الذكاء الاصطناعي محلياً (`local-ai`)

- **الغرض:** ذكاء اصطناعي مستضاف ذاتياً عبر Ollama — دون الحاجة إلى مفاتيح API
- **الميزات الأساسية:** تكامل Ollama، خدمة النماذج محلياً، الحفاظ على الخصوصية
- **التخصيص:** بدّل النماذج عبر متغير البيئة `OLLAMA_MODEL`
