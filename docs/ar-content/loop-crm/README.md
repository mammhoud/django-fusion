# 🤝 Loop-CRM — CRM موحد للمبيعات والتسويق

> نظام موحد للمبيعات + التسويق (نسل Twenty + Postiz) على Django + django-fusion. المسار المعياري للمنتج: `projects/loop-crm/`.

---

## نظرة عامة

Loop-CRM يدمج DNA من Twenty (CRM) و Postiz (الجدولة الاجتماعية) في منصة موحدة للمبيعات والتسويق. مبنية على Django + django-fusion مع ドラマتيك للعمالة الخلفية.

---

## البدء السريع

```bash
cd projects/loop-crm
make dev
```
