## 1. Quick Summary

| Concern | Path / Value | Why |
|---------|--------------|-----|
| Site directory | `core/ctc-research/` | All CTC-specific code, templates, and assets |
| Webpack entry (JS) | `core/ctc-research/assets/static/js/app.js` | Site-specific JS entry point |
| Webpack entry (CSS) | `core/ctc-research/assets/static/js/static.js` | Imports `main.scss` to produce the CSS bundle |
| Webpack output | `core/ctc-research/assets/bundles/ctc-research/` | Hashed JS/CSS + `bundles.json` manifest |
| Django `STATIC_ROOT` | `core/ctc-research/assets/staticfiles/` | `collectstatic` destination |
| Django `STATIC_URL` | `/static/` | URL prefix for static files |
| Django `MEDIA_ROOT` | `core/ctc-research/assets/media/` | User-uploaded files on disk |
| Django `MEDIA_URL` | `/media/` | URL prefix for media files |
| Shared media container | `shared-media` (Nginx) | Serves `/static/` and `/media/` for all sites |
| Traefik media router | `media.ctc-research.com` | Dedicated hostname for CTC media |

## 2. Template Bundle Tags

The shared base template at [`core/assets/templates/base.html`](../../../core/assets/templates/base.html) loads the three canonical webpack chunks:

```django
{% load webpack_loader %}

{# CSS in <head> #}
{% block css %}
    {% render_bundle 'static' 'css' %}
{% endblock %}

{# JS before </body> #}
{% render_bundle 'main' 'js' %}
{% render_bundle 'app' 'js' %}
```

| Bundle | Type | Contents | Source |
|--------|------|----------|--------|
| `static` | CSS + JS | Vendor CSS, site SCSS, tiny runtime shim | `ctc-research/assets/static/js/static.js` → imports `styles/main.scss` |
| `main` | JS | Shared core libraries (HTMX, Alpine, theme init) | `core/assets/static/js/core/main.js` |
| `app` | JS | CTC-specific logic and HTMX lifecycle bridge | `ctc-research/assets/static/js/app.js` |

### 2.1 What `render_bundle` produces

`django-webpack-loader` reads `bundles.json` (generated by `webpack-bundle-tracker`) and emits tags like:

```html
<link rel="stylesheet" href="/static/bundles/ctc-research/static-a1b2c3d4.css">
<script src="/static/bundles/ctc-research/main-e5f6g7h8.js"></script>
<script src="/static/bundles/ctc-research/app-i9j0k1l2.js"></script>
```

The `BUNDLE_DIR_NAME` setting is `bundles/ctc-research/`, so the final URL is always `/static/bundles/ctc-research/<file>`.

## 3. Webpack Build Flow

```bash
# Build CTC bundles (production)
npm --prefix core/assets run build:ctc

# Or from the site directory
cd core/ctc-research
make frontend-production
```

Under the hood:

1. `workspace.mjs` resolves `ctc` → `ctc-research`.
2. `webpack/main.config.js` sets:
   - `entry.app` → `ctc-research/assets/static/js/app.js`
   - `entry.static` → `ctc-research/assets/static/js/static.js`
   - `entry.main` → `core/assets/static/js/core/main.js`
   - `output.path` → `ctc-research/assets/bundles/ctc-research/`
   - `output.publicPath` → `/static/bundles/ctc-research/`
3. `BundleTracker` writes `bundles.json` in the same output directory.

### 3.1 Collectstatic

```bash
cd core/ctc-research
python manage.py collectstatic --noinput
```

This copies:
- Webpack bundles from `assets/bundles/ctc-research/` → `assets/staticfiles/bundles/ctc-research/`
- Shared static sources from `core/assets/static/` → `assets/staticfiles/`
- Site static sources from `ctc-research/assets/static/` → `assets/staticfiles/site/ctc-research/`

### 3.2 Resulting static tree (simplified)

```
core/ctc-research/assets/staticfiles/
├── bundles/
│   └── ctc-research/
│       ├── bundles.json
│       ├── static-a1b2c3d4.css
│       ├── static-e5f6g7h8.js
│       ├── main-i9j0k1l2.js
│       └── app-j3k4l5m6.js
├── site/
│   └── ctc-research/
│       └── images/
│           └── logo.png
└── wagtailadmin/
    └── ...
```

## 4. Static & Media Paths

### 4.1 Django settings

From [`core/configs/base/assets.py`](../../../core/configs/base/assets.py):

```python
ASSETS_DIR = BASE_DIR / "assets"          # core/ctc-research/assets
MEDIA_DIR  = ASSETS_DIR / "media"          # core/ctc-research/assets/media
STATIC_DIR = ASSETS_DIR / "static"         # core/ctc-research/assets/static

MEDIA_ROOT = str(MEDIA_DIR)                # /app/ctc-research/assets/media
MEDIA_URL  = "/media/"

STATIC_ROOT = str(ASSETS_DIR / "staticfiles")  # /app/ctc-research/assets/staticfiles
STATIC_URL  = "/static/"

STATICFILES_DIRS = [
    ("bundles/ctc-research", "ctc-research/assets/bundles/ctc-research"),
    ("bundles/shared",       "core/assets/bundles/shared"),
    (None,                   "core/assets/static"),
    ("site/ctc-research",    "ctc-research/assets/static"),
]
```

### 4.2 URL-to-disk mapping

| URL | Disk path (inside container) | Served by |
|-----|-------------------------------|-----------|
| `/static/bundles/ctc-research/static-a1b2c3d4.css` | `/app/ctc-research/assets/staticfiles/bundles/ctc-research/static-a1b2c3d4.css` | Django dev server OR `shared-media` |
| `/static/images/logo.png` | `/app/ctc-research/assets/staticfiles/site/ctc-research/images/logo.png` | `shared-media` |
| `/media/ctc-research/avatars/user1.png` | `/app/ctc-research/assets/media/avatars/user1.png` | `shared-media` |

In production, Traefik routes all `/static/` and `/media/` requests on `ctc-research.com` to the `shared-media` Nginx container, so Django never touches them.

## 5. Shared Media Server

### 5.1 Container mounts

From [`applications/proxy/docker-compose.nginx.yml`](../../../applications/proxy/docker-compose.nginx.yml):

```yaml
services:
  shared-media:
    volumes:
      # Site build output staticfiles
      - ../core/ctc-research/assets/staticfiles:/var/www/sites/ctc-research/static:ro
      - ../core/lms-demo/assets/staticfiles:/var/www/sites/lms-demo/static:ro
      - ../core/VResume/assets/staticfiles:/var/www/sites/vresume/static:ro
      # Shared application static files
      - ../core/assets/static:/var/www/static:ro
      # Site-specific media uploads
      - ../core/ctc-research/assets/media:/var/www/media/ctc-research:ro
      - ../core/lms-demo/assets/media:/var/www/media/lms-demo:ro
      - ../core/VResume/assets/media:/var/www/media/vresume:ro
```

### 5.2 Nginx locations

From [`applications/proxy/nginx/default.conf`](../../../applications/proxy/nginx/default.conf):

```nginx
# Webpack bundles (immutable, 1 year cache)
location /static/bundles/ctc-research/ {
    alias /var/www/sites/ctc-research/static/bundles/ctc-research/;
    expires 1y;
    add_header Cache-Control "public, immutable";
}

# Site-specific static files
location /sites/ctc-research/static/ {
    alias /var/www/sites/ctc-research/static/;
    expires 1y;
}

# Site-specific media files
location /media/ctc-research/ {
    alias /var/www/media/ctc-research/;
    expires 30d;
}

# Shared static / media fallbacks
location /static/ { alias /var/www/static/; }
location /media/  { alias /var/www/media/; }
```

### 5.3 Traefik routing

From [`applications/proxy/traefik/dynamic/ctc-research.yml`](../../../applications/proxy/traefik/dynamic/ctc-research.yml):

```yaml
http:
  routers:
    ctc-site-media-https:
      rule: >
        (Host(`ctc-research.com`) || Host(`www.ctc-research.com`) || Host(`arch.ctc-research.com`))
        && (PathPrefix(`/static/`) || PathPrefix(`/media/`) || PathPrefix(`/sites/`))
      entryPoints: [web-secure]
      service: ctc-site-media-service
      priority: 100
  services:
    ctc-site-media-service:
      loadBalancer:
        servers:
          - url: 'http://shared-media:80'
```

And from [`applications/proxy/traefik/dynamic/media-servers.yml`](../../../applications/proxy/traefik/dynamic/media-servers.yml):

```yaml
http:
  routers:
    ctc-media-https:
      rule: Host(`media.ctc-research.com`)
      entryPoints: [web-secure]
      service: ctc-media-service
      tls:
        certResolver: letsencrypt-http
  services:
    ctc-media-service:
      loadBalancer:
        servers:
          - url: http://shared-media:80
```

## 6. Verification

Run the dedicated audit script:

```bash
python scripts/verify_ctc_assets.py
```

It checks:
1. Templates use only known bundle names (`static`, `main`, `app`).
2. Django settings, webpack config, Nginx, and Traefik agree on paths.
3. Volume mounts in `applications/proxy/docker-compose.nginx.yml` point to the right directories.
4. `bundles.json` exists after a build (optional `--strict` flag).

See [`scripts/verify_ctc_assets.py`](../../../scripts/verify_ctc_assets.py) for details.

## 8. Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| `render_bundle` returns empty | `bundles.json` missing or invalid | Run `npm --prefix core/assets run build:ctc` |
| 404 on `/static/bundles/ctc-research/...` | `collectstatic` not run or Nginx not mounted | Run `collectstatic`, restart `shared-media` |
| 404 on uploaded media | `MEDIA_ROOT` not mounted into `shared-media` | Check `applications/proxy/docker-compose.nginx.yml` volumes |
| Mixed-content warnings | `STATIC_URL`/`MEDIA_URL` use `http://` behind HTTPS | Set `SECURE_PROXY_SSL_HEADER` and use relative URLs |
| Old bundle served after deploy | Browser cache / immutable headers | Hard-refresh or bump cache key via webpack hash |
