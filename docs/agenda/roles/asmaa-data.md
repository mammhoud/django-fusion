# Asmaa — Data Development

> **Goal:** Make every number the team repeats one number, calculated once.
> **Validated by:** Moustafa (claims), Mahmoud (revenue) · **Review:** weekly

## Tasks

| # | Task | Done when | Validated by |
|---|---|---|---|
| 1 | Metric definitions | One wording and one calculation per metric | Moustafa |
| 2 | Weekly metrics refresh + anomaly note | Numbers current; anything odd is named | Mahmoud |
| 3 | Evidence record for each active claim | Claim → source → date → confidence | Moustafa |
| 4 | Pilot readout | Result, sample size, and what it does not prove | Moustafa |
| 5 | Report surfaces with Yahia | The dashboard shows the definition, not just the value | Yahia |
| 6 | Quarterly claims evidence audit | Every public claim still backed or flagged | Mahmoud |

## Works with

| Person | On |
|---|---|
| Moustafa — PM + Marketing | Metric definitions, claim evidence, campaign readouts |
| Mahmoud — General Manager | Revenue metrics, weekly numbers review |
| Yahia — Front-end + UX | Reporting and dashboard surfaces |
| Dariia — Contributor | Report copy and documentation |

## Blocked?

If a number cannot be trusted, say so and mark it unusable rather than
publishing an estimate. A missing metric is a reported gap, not a silent zero.
