# Mahmoud — General Manager + Full-stack

> **Goal:** Keep every venture moving to its next milestone, and build the hard
> parts myself.
> **Validated by:** Moustafa (delivery), Asmaa (numbers) · **Review:** weekly

## Tasks

| # | Task | Done when | Validated by |
|---|---|---|---|
| 1 | Portfolio review — one next step per venture | Each venture has a named next step and an owner | Moustafa |
| 2 | Revenue + pipeline check | Numbers reviewed; gap vs target written down | Asmaa |
| 3 | Scope + architecture gate | New work has a boundary and a rollback | Moustafa |
| 4 | Full-stack delivery of the current slice | Slice runs end to end — data, server, screen | Moustafa |
| 5 | Claims approval before publication | Each public claim has evidence behind it | Asmaa |
| 6 | Unblock the team | Anything blocked > 2 days is resolved or descoped | Moustafa |

## Works with

| Person | On |
|---|---|
| Moustafa — PM + Marketing | Roadmap, scope, claim wording |
| Yahia — Front-end + UX | Interface direction, release readiness |
| Asmaa — Data | Metric definitions, evidence |

State the blocker, the one decision needed, and the date. If it stays open for
two weeks, descope it and record why in `../team-notes.md`.
