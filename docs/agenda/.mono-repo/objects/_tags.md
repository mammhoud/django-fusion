# Tags — Documentation System

> **Import Instruction:** Create a Multi-select Property named "Tags" in your **Channel** (Anytype container — formerly Space) and add these options.
> Apply to documentation objects for cross-cutting categorization.
> **Channel model:** the container is not a tag — see [`guides/channel-structure.md`](../guides/channel-structure.md). The `#channel` tags below refer to *marketing/distribution channels*, which are `Integration` objects, not the Anytype Channel container.
