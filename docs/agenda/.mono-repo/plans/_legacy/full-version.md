# Full Version — Enterprise Edition

> **Type:** Workspace 🏢
> **Description:** The enterprise edition of the POS system — multi-branch management, cloud sync, CRM integration, and premium support.

> **Legacy:** Archived with the deprecated version labels (`pos-mini` / `pos-solo` / `pos-full`). See `../../architecture/editions.md` for current edition scope.

---

## Overview

The Full Version (Enterprise Edition) adds on top of Solo:

| Capability | Description | Status |
|------------|-------------|--------|
| **Multi-Branch** | Manage multiple restaurant locations | 🚧 In Development |
| **Cloud Sync** | Central cloud API for data aggregation | 🚧 In Development |
| **CRM Integration** | Customer profiles, loyalty, marketing | 📋 Planned |
| **Advanced Analytics** | Cross-branch reports, forecasting | 📋 Planned |
| **Role Management** | Granular permissions per branch | ✅ Complete |
| **Professional Support** | Dedicated support, SLA, training | 📋 Planned |
