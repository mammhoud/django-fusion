# Achievement Board — Goals as a Tracker

> **Type:** Goal / Milestone 🎯
> **Description:** A live tracker of the project's achieved goals and milestones, organized by the story phases that delivered them. Use this as both a goal tracker and an achievement board.

---

## How to use this board

- Each **phase** below corresponds to a chapter of the story.
- Each row is a **goal** or **milestone** that has been **achieved**.
- Newly completed work moves from "planned" into the achieved rows as evidence is recorded.
- Anything still in progress stays at the bottom under "In progress".
