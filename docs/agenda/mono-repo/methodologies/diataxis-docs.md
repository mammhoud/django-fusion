# DIÁTAXIS — Documentation Method

> **Description:** The four-quadrant documentation framework — tutorials (learning), how-to guides (tasks), reference (facts), explanation (understanding) — used across the docs tree.

## Steps

1. Classify each doc: Tutorial / How-to / Reference / Explanation
2. Match audience + acquisition/application dimensions
3. Keep reference authoritative and versioned
4. Cross-link quadrants so users move between them

## Use

Applied by the documentation writer skill and the `../../CONTENT_MODEL.md` packaging rules — every doc knows its quadrant and home directory.
