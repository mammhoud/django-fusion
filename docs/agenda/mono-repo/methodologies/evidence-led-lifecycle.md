# Evidence-Led Product Lifecycle

> **Description:** Research → Plan → Build → Ship → Learn, with every claim backed by recorded evidence before it becomes a marketing statement.

## Steps

1. Market research (hypotheses + validation questions)
2. Plan with measurable milestones
3. Build against per-edition plans
4. Ship with acceptance criteria met
5. Record evidence (case studies, metrics, pilots)
6. Update claims register (`../plans/marketing-campaigns.md` claims proof)

## Use

The product-development plan (`../plans/product-development.md`) is the canonical expression; this object is the reusable method.
