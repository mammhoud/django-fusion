# Data Analyst Operating Model — Weekly & Quarterly Rhythms

> **Description:** The data analyst's delivery rhythms — weekly product metrics, experiment framework, and quarterly evidence reviews (mirrors `../../data-analyst-plans.md`).

## Findings

- Weekly: product-level metrics + pilot status
- Per release: evidence for shipped claims
- Quarterly: market research validation, positioning updates
- Active pilots tracked with explicit experiment designs

## Recommendations

- Use the evidence-led lifecycle methodology for every claim
- Reports link to dashboards and insights; insights drive recommendations
