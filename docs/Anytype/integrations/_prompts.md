# Integrations — AI Agent Prompts

## Creating Integration Docs

```
Create an integration document at `docs/Anytype/integrations/[provider-name].md`.

Include:
1. Frontmatter with Object type: Integration, Category, Provider, Status
2. Integration overview and purpose
3. Authentication method (API key, OAuth, JWT)
4. Setup and configuration steps
5. API endpoints used
6. Rate limits and quotas
7. Related features and pipelines
```

## Reviewing Integrations

```
Review integration documentation:
1. Verify authentication details are accurate
2. Check rate limits and quotas
3. Ensure error handling is documented
4. Verify setup steps are complete
5. Check edition compatibility
```
