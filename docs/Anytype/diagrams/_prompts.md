# Diagrams — AI Agent Prompts

## Creating Diagrams

```
Create a diagram document at `docs/Anytype/diagrams/[name].md`.

Include:
1. Frontmatter with Object type: Diagram, Type
2. Diagram title and purpose
3. ASCII or Mermaid diagram
4. Explanation of components/flows
5. Related architecture docs
```

## Reviewing Diagrams

```
Review diagrams for accuracy:
1. Does the diagram match the code/architecture?
2. Are labels clear and consistent?
3. Is the ASCII formatting aligned properly?
4. For Mermaid: does it render correctly?
5. Are cross-references to related docs included?
```
