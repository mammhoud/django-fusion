# Goals — AI Agent Prompts

## Creating Goal Docs

```
Create a goal document at `docs/Anytype/goals/[name].md`.

Include:
1. Frontmatter with Object type: Goal, Status, Category, Priority
2. Goal statement and scope
3. Key Results (measurable outcomes)
4. Related features and tasks
5. Target date and milestones
6. Owner and stakeholders
```

## Reviewing Goals

```
Review goals for alignment:
1. Are Key Results measurable?
2. Are related tasks defined?
3. Is the priority correct?
4. Are dependencies identified?
5. Does the goal align with project direction?
```
