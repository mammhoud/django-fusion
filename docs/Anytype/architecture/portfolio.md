# Portfolio — VResume Professional Portfolio System

> **Type:** Feature ✨
> **Description:** The VResume portfolio and resume builder — create, customize, and publish professional portfolios across multiple templates.

---

## Overview

VResume powers professional portfolio creation with:

| Capability | Description |
|------------|-------------|
| **Portfolio Builder** | Drag-and-drop section management via Wagtail |
| **Resume Builder** | Professional resume with configurable templates |
| **Theme Selection** | Multiple visual themes with customizable colors |
| **AI Assistance** | Ceptor AI-powered content suggestions |
| **PDF Export** | Download resume as formatted PDF |
