# Architecture Docs — AI Agent Prompts

> Specialized prompts for working with architecture documentation.

---

## Creating Architecture Docs

```
Create an architecture document at `docs/Anytype/architecture/[name].md`.

Include:
1. Frontmatter with Object type: Architecture, Tags, Status
2. High-level system description
3. ASCII diagram showing system components and data flow
4. Technology stack table
5. Key architectural decisions with rationale
6. Related docs links using → format
```

## Reviewing Architecture

```
Review the architecture documentation:
1. Check that all components are described
2. Verify data flow accuracy
3. Ensure technology stack is up to date
4. Check that diagrams use consistent notation
5. Verify cross-references to features and guides
```
