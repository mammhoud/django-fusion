# Projects — AI Agent Prompts

## Creating Project Docs

```
Create a project document at `docs/Anytype/projects/[name].md`.

Include:
1. Frontmatter with Object type: Project, Status, Start Date
2. Project overview and scope
3. Goals and objectives
4. Related plans and milestones
5. Team and ownership
6. Status updates and progress
```

## Reviewing Projects

```
Review project documentation:
1. Are project goals clearly defined?
2. Are plans and milestones linked?
3. Is the project scope documented?
4. Are risks and blockers identified?
5. Is ownership assigned?
```
