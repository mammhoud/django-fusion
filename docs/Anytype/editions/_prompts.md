# Editions — AI Agent Prompts

## Creating Edition Docs

```
Create an edition document at `docs/Anytype/editions/[name].md`.

Include:
1. Frontmatter with Object type: Edition, Status, Version
2. Edition overview and target audience
3. Included and excluded features
4. Technical stack and dependencies
5. Pricing tier and licensing
6. Related features and goals
```

## Reviewing Editions

```
Review edition documentation:
1. Are included/excluded features accurate?
2. Is the pricing tier documented?
3. Are technical requirements listed?
4. Is the target audience clear?
5. Are upgrade paths documented?
```
