# Blog — AI Agent Prompts

## Creating Blog Posts

```
Create a blog post at `docs/Anytype/blog/[slug].md`.

Include:
1. Frontmatter with Object type: Blog/Post, Status, Author, Published Date
2. Engaging title and excerpt
3. Introduction setting the context
4. Structured body with headings
5. Code examples where applicable
6. Related features and guides
7. Author bio and links
```

## Reviewing Blog Posts

```
Review blog posts for quality:
1. Is the title compelling and accurate?
2. Is the target audience clear?
3. Are technical details correct?
4. Are code examples tested and working?
5. Are cross-references to docs accurate?
```
