# Plans Docs — AI Agent Prompts

> Specialized prompts for working with business and project planning documentation.

---

## Creating Plan Docs

```
Create a plan document at `docs/Anytype/plans/[name].md`.

Include:
1. Frontmatter with Object type, Tags, Status
2. Executive summary
3. Structured sections with tables where applicable
4. Data-driven insights and metrics
5. Related plans and task links
```

## Linking Plans to Tasks

```
Review plan-to-task alignment:
1. Check that each plan links to relevant tasks
2. Verify milestone dates match task schedules
3. Ensure risk mitigations have corresponding tasks
4. Check resource allocation matches team capacity
5. Link market research findings to feature priorities
```
