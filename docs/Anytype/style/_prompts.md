# Style — AI Agent Prompts

## Creating Style Docs

```
Create a style/token document at `docs/Anytype/style/[name].md`.

Include:
1. Frontmatter with Object type: Style, Category, Token, Value
2. Token name and CSS variable
3. Value (hex, rem, px, etc.)
4. Usage examples and best practices
5. Related components that consume this token
6. Theme variant overrides if applicable
```

## Reviewing Styles

```
Review style documentation:
1. Verify hex/values match actual CSS
2. Check dark mode variants are documented
3. Ensure accessibility contrast is noted
4. Verify token naming follows conventions
```
