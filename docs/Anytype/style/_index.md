# Style — Design Tokens & Theme

> **Type:** Style 🎨
> **Description:** Design tokens, color palettes, typography, spacing, shadows, animations, and brand guidelines for all Structa Cloud applications and POS editions.

---

## Design Token Categories

| Category | Tokens | Example |
|----------|--------|---------|
| **Color** | `--color-teal-*`, `--color-slate-*` | Primary & surface colors |
| **Typography** | Font family, size, weight, line-height | Inter, system fonts |
| **Spacing** | Padding, margin, gap values | `p-4`, `m-2`, `gap-3` |
| **Shadow** | Box shadow tokens | `shadow-sm`, `shadow-lg` |
| **Animation** | Transition, duration, easing | `transition-all`, `duration-300` |
| **Border** | Radius, width, style | `rounded-lg`, `border-2` |
