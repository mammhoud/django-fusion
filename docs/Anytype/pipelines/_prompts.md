# Pipelines — AI Agent Prompts

## Creating Pipeline Docs

```
Create a pipeline document at `docs/Anytype/pipelines/[name].md`.

Include:
1. Frontmatter with Object type: Pipeline, Type, Provider, Status
2. Pipeline overview and purpose
3. Trigger conditions
4. Step-by-step workflow description
5. Environment variables and secrets
6. Related releases and references
```
