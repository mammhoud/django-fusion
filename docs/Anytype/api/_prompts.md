# API — AI Agent Prompts

## Creating API Docs

```
Create an API endpoint document at `docs/Anytype/api/[name].md`.

Include:
1. Frontmatter with Object type: API, Method, Endpoint, Status
2. Endpoint URL and method
3. Request/response schema (JSON)
4. Authentication requirements
5. Error codes and handling
6. Edition availability
7. Related features and components
```

## Reviewing APIs

```
Review API documentation:
1. Verify endpoint paths match implementation
2. Check request/response schemas against actual behavior
3. Ensure auth requirements are documented
4. Verify rate limits are accurate
5. Check error codes cover all edge cases
```
