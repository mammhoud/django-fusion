# Tasks Docs — AI Agent Prompts

> Specialized prompts for working with task and backlog documentation.

---

## Creating Task Docs

```
Create a task document at `docs/Anytype/tasks/[name].md`.

Include:
1. Frontmatter with Object type: Task, Status, Priority, Edition tags
2. Task description and scope
3. Acceptance criteria
4. Dependencies on other tasks
5. Related goals and milestones
6. Links to implementation guides
```

## Reviewing Task Status

```
Review the task backlog:
1. Update task statuses based on git history
2. Check that completed tasks have verification notes
3. Ensure blocked tasks have blockers documented
4. Verify priority alignment with goals
5. Check that edition tags are correct
```
