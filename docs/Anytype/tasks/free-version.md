## Overview

The Free Version (Community Edition) includes:

| Feature | Included | Limits |
|---------|----------|--------|
| **Self-Hosted Deployment** | ✅ | Unlimited |
| **Open Source Code** | ✅ | Full access (MIT license) |
| **django-fusion Library** | ✅ | Full features |
| **All Sites** (CTC Research, LMS Demo, VResume, Tinker) | ✅ | Full access |
| **AI-Assisted Content** | ✅ | Limited API calls/month |
| **SSL via Traefik** | ✅ | Let's Encrypt included |
| **Community Support** | ✅ | GitHub Issues + Discord |
| **Professional Support** | ❌ | Requires paid plan |
