# Decisions — AI Agent Prompts

## Creating ADRs

```
Create an ADR at `docs/Anytype/decisions/[number]-[title].md`.

Template:
1. Frontmatter with Object type: Decision, Status, Category
2. Context — what prompted this decision
3. Options considered (bulleted list)
4. Decision — what was chosen and why
5. Consequences — positive and negative trade-offs
6. Related architecture docs
7. Supersedes/superseded-by links
```

## Reviewing Decisions

```
Review ADRs for completeness:
1. Is the context clearly described?
2. Are alternatives documented?
3. Are consequences (pro/con) balanced?
4. Is the status current?
5. Are there related architecture references?
```
