# Releases — AI Agent Prompts

## Creating Release Docs

```
Create a release document at `docs/Anytype/releases/[version-name].md`.

Include:
1. Frontmatter with Object type: Release, Version, Status
2. Release overview and scope
3. New features with links to feature docs
4. Bug fixes with links to related tasks
5. Breaking changes and migration notes
6. Deployment instructions
7. Related pipeline and milestone links
```
