# Features Docs — AI Agent Prompts

> Specialized prompts for working with feature documentation.

---

## Creating Feature Docs

```
Create a feature document at `docs/Anytype/features/[name].md`.

Include:
1. Frontmatter with Object type: Feature, edition tags, status
2. Feature overview and purpose
3. Key capabilities with bullet points
4. Edition compatibility matrix
5. Technical implementation details
6. Related guides and references
```

## Updating Feature Matrix

```
Update the feature comparison matrix:
1. Add new feature rows as needed
2. Mark edition compatibility (✅/🚧/📋/🔄)
3. Check consistency with individual feature docs
4. Verify all editions are represented
```
