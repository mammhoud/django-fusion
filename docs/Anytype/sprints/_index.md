# Sprints — Cycle Tracking

> **Type:** Sprint 🏃
> **Description:** Sprint cycle tracking with goals, task assignments, velocity, and retrospective notes.

---

## Sprint Lifecycle

| Phase | Status | Activities |
|-------|--------|------------|
| **Planning** | Planning | Goal setting, backlog grooming, estimation |
| **Active** | Active | Daily standups, task execution, code review |
| **Review** | Completed | Demo, stakeholder feedback |
| **Retrospective** | Completed | What went well, what to improve |

---

## Sprint Structure

| Element | Description |
|---------|-------------|
| **Duration** | 2 weeks (standard) |
| **Capacity** | Story points per sprint |
| **Planning** | First day of sprint |
| **Review** | Last day of sprint |
| **Retro** | After review |
