# Sprints — AI Agent Prompts

## Creating Sprint Docs

```
Create a sprint document at `docs/Anytype/sprints/[sprint-number].md`.

Include:
1. Frontmatter with Object type: Sprint, Sprint Number, Status
2. Sprint goals and scope
3. Team members and assignments
4. Key tasks and deliverables
5. Retrospective notes
6. Velocity and burndown metrics
7. Related milestones and releases
```

## Reviewing Sprints

```
Review sprint documentation:
1. Are sprint goals clearly defined?
2. Are all tasks linked to the sprint?
3. Are retrospective notes actionable?
4. Is team capacity documented?
5. Are blockers identified and tracked?
```
