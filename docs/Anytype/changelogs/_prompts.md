# Changelogs Docs — AI Agent Prompts

> Specialized prompts for working with version history and changelog documentation.

---

## Creating Changelog Entries

```
Add a changelog entry to `docs/Anytype/changelogs/[name].md`.

Format:
## [YYYY-MM-DD] — Version

### Added
- New features and capabilities

### Fixed
- Bug fixes and corrections

### Changed
- Modifications to existing functionality

### Deprecated
- Features scheduled for removal

### Removed
- Features removed in this version
```

## Reviewing Changelogs

```
Review changelog entries:
1. Verify version numbers follow semantic versioning
2. Check that all Added items link to feature docs
3. Ensure Fixed items reference related tasks
4. Verify dates are chronological
5. Check that edition tags match the changes
```
