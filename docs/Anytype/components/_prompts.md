# Components — AI Agent Prompts

## Creating Component Docs

```
Create a component document at `docs/Anytype/components/[name].md`.

Include:
1. Frontmatter with Object type: Component, Category, Status
2. Component overview and purpose
3. Props/API interface table
4. Usage examples with React code
5. Theme variant appearance notes
6. Related style tokens and API endpoints
```

## Reviewing Components

```
Review component documentation:
1. Verify props/API match actual implementation
2. Check theme variant compatibility
3. Ensure accessibility notes are included
4. Verify related style tokens exist
5. Check edition compatibility
```
