# Components — Reusable UI & Business Components

> **Type:** Component 🔧
> **Description:** Reusable UI components from the django-fusion library and POS frontend — buttons, cards, forms, navigation, data displays, and layout primitives.

---

## Component Categories

| Category | Examples | Framework |
|----------|----------|-----------|
| **UI** | Button, Card, Badge, Modal, Tooltip | React + Tailwind |
| **Form** | Input, Select, Checkbox, DatePicker, FileUpload | React + django-fusion |
| **Navigation** | Sidebar, Navbar, Breadcrumb, Tabs, Pagination | React |
| **Data** | Table, List, Chart, Calendar, Kanban | React |
| **Layout** | Grid, Container, Section, Sidebar, Header | React + Tailwind |
| **Widget** | Chat, Notifications, SearchBar, CommandPalette | React |
