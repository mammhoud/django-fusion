# Milestones — AI Agent Prompts

## Creating Milestone Docs

```
Create a milestone document at `docs/Anytype/milestones/[name].md`.

Include:
1. Frontmatter with Object type: Milestone, Status, Due Date
2. Milestone description and scope
3. Deliverables and acceptance criteria
4. Related goals and tasks
5. Dependencies and risks
6. Related release or plan
```
