# References Docs — AI Agent Prompts

> Specialized prompts for working with API and configuration reference documentation.

---

## Creating References

```
Create a reference document at `docs/Anytype/references/[name].md`.

Include:
1. Frontmatter with Object type: Reference, Category, Edition tags
2. Purpose and scope description
3. Organized reference content (tables, code blocks, lists)
4. Code examples where applicable
5. Related docs links
```

## Reviewing References

```
Review reference documentation:
1. Verify API endpoints match actual implementation
2. Check that command arguments are complete
3. Ensure database schemas reflect current models
4. Verify i18n keys are up to date
5. Check that edition-specific notes are accurate
```
