## 💡 Key Concepts at a Glance

| Concept | File | Import Path | Quick Description |
|---------|------|------------|-------------------|
| **Site** | [ARCHITECTURE_OVERVIEW](./ARCHITECTURE_OVERVIEW.md) | `from django_fusion.comp.routes import Site` | Top-level container for all components |
| **Application** | [COMPONENT_SYSTEM](./COMPONENT_SYSTEM.md) | `from django_fusion.comp.routes import Application` | Groups related components |
| **RoutableComponent** | [COMPONENT_SYSTEM](./COMPONENT_SYSTEM.md) | `from django_fusion.comp.routes import RoutableComponent` | Full page view component |
| **FragmentComponent** | [COMPONENT_SYSTEM](./COMPONENT_SYSTEM.md) | `from django_fusion.comp.routes import FragmentComponent` | HTMX fragment for partial updates |
| **Route** | [ROUTING_SYSTEM](./ROUTING_SYSTEM.md) | `from django_fusion.comp.routes import route, Route` | URL path configuration |
| **FormMixin** | [FORMS_TABLES_INTEGRATION](./FORMS_TABLES_INTEGRATION.md) | `from django_fusion.comp.routes import FormMixin` | Form rendering integration |
| **TableMixin** | [FORMS_TABLES_INTEGRATION](./FORMS_TABLES_INTEGRATION.md) | `from django_fusion.comp.routes import TableMixin` | Table rendering integration |
| **Analyzer** | [COMPONENT_ANALYZER](./COMPONENT_ANALYZER.md) | `from django_fusion.analyzer import scanner, parser` | Template scanner & component analysis |
