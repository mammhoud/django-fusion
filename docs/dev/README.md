# Development documentation moved

The former `docs/dev/` documentation tree was a parallel archive and planning system. Planning is now centralized under the main documentation project:

- [Recommendations first](../recommendations.md)
- [Canonical plans](../plans/README.md)
- [Archived development plans](../plans/legacy/dev-plans/README-archived.md)
- [Documentation lifecycle](../plans/document-lifecycle.md)

Current guides, architecture references, deployment procedures, and project documentation remain in their dedicated sections under [`docs/README.md`](../README.md). Historical development records that were previously under `docs/dev/plans/` are preserved under `docs/plans/legacy/dev-plans/` and are not active scope.

> **Do not add new plans here.** Add them to `docs/plans/<scope>/` and link them from the canonical registry.
