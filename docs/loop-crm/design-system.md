# Loop-CRM Design System

The canonical design-system document lives in the product repo:

> [**`projects/loop-crm/docs/DESIGN_SYSTEM.md`**](../../projects/loop-crm/docs/DESIGN_SYSTEM.md)

It defines the industrial-brutalist / tactical-telemetry design language used
across the Loop-CRM frontend shell and the Django-rendered data screens:

- **Archetype:** Tactical Telemetry & CRT Terminal (dark substrate, mono telemetry type, hazard-red accent).
- **Tokens:** `#0a0a0a` substrate, `#e61919` hazard red, `#4af626` terminal green (live-sync only).
- **Geometry:** zero border-radius, `gap: 1px` blueprint grids, hard 1px/2px borders.
- **Components:** fusion table + form overrides render through the same language.

See the [Loop-CRM index](README.md) for setup commands and architecture notes.
