# Portfolio — Use Cases

## 1. Professional Resume Builder (`resume`)

- **Purpose:** Create, customize, and publish professional resumes
- **Key features:** Wagtail CMS resume templates, PDF export, rich text editing
- **Customization:** Add resume templates, custom sections (skills, education, experience)

## 2. Portfolio Website (`portfolio`)

- **Purpose:** Showcase work experience, projects, achievements
- **Key features:** Portfolio sections, image galleries, project descriptions
- **Customization:** Add portfolio categories, custom layouts

## 3. Personal Branding Site (`branding`)

- **Purpose:** Personal website with blog, about page, contact form
- **Key features:** Wagtail blog, social auth, contact forms, events
- **Customization:** Custom color themes, font selections, layout options

## 4. PDF Export Service (`pdf-export`)

- **Purpose:** Generate print-ready PDF versions of resumes and portfolios
- **Key features:** Wagtail-rendered PDF templates, custom paper sizes
- **Customization:** PDF template designs, watermark support
