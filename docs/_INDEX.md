## 🏗️ System Architecture

The documentation covers the following architecture:

```
CTC-Research Website (Production)
├── Frontend Layer
│   ├── Wagtail CMS
│   ├── Static Files (1848+)
│   └── Multi-language Support
├── Application Layer
│   ├── Django (LMS Module)
│   ├── Gunicorn + ASGI
│   └── 4 Worker Processes
├── Database Layer
│   ├── PostgreSQL
│   └── Fully Migrated Schema
└── Infrastructure
    ├── Docker Containers
    ├── Docker Network
    └── SSL/TLS (via Traefik)
```
