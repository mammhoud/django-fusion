# Task: Refactor to a Design Pattern

Analyse a set of files (or a module) and propose a refactoring to a specific OOP/design pattern:
- Factory, Strategy, Observer, Repository, Service Layer, etc.

**Input**: User provides the target pattern and the files.  
**Output**: A step‑by‑step plan, plus code snippets. If approved, apply changes with a `# REFACTORED` comment.
