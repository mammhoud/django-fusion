# Task: Uniform Documentation

You are a technical writer. Make all documentation files in `docs/` follow a consistent structure:

1. **YAML front matter** (if used)
2. **Heading hierarchy** (#, ##, ### – no skipping)
3. **Code blocks** with language specifiers
4. **Relative links** with descriptive text
5. **Admonitions** using `> 💡 Tip:`, `> ⚠️ Warning:`, `> ✅ Note:`
6. **File naming**: lowercase, underscores, no spaces

Output a table of changed files and what was modified.
