# AI Assistant for Django – Documentation

Welcome to the complete guide for setting up a **private, offline AI coding assistant** using Ollama and Continue, plus the **AI Customizer** script for advanced project interaction.

## Available Tasks

Run `make task-list` to see all tasks. Key tasks:

- `comprehensive_analysis` – full analysis with package check, structure mapping, N+1, duplications, and phased actions
- `analyze_project` – detailed report with TODO comments and N+1 detection
- `uniform_docs` – standardise all documentation files
- `merge_styles`, `replace_pattern`, `refactor_design_pattern` – context‑aware code transformations

## 🚀 Quick Start

1. **Set up the base assistant** → [setup.md](setup.md)
2. **Run the customizer script** (optional but powerful) → [customizer.md](customizer.md)
3. **Tweak performance** → [config.md](config.md)

All code remains **local** – no cloud, no API keys.
