## 6. Privacy and Independence

A core design principle is to respect client privacy and enable independent use without sharing code or data with the licensor.

### Privacy-First Architecture
- **No Telemetry** – The software contains no “phone‑home” features.
- **Local Execution** – All operations run entirely within client infrastructure.
- **No Data Collection** – Client data never leaves their systems.
- **Configuration Control** – All settings are exposed for local modification.

### Independent Update Capability
Commercial licensees receive access to a private update mechanism, allowing them to:
- Apply security patches and feature updates at their own schedule.
- Test updates in staging environments.
- Modify configuration files without assistance.
- Integrate updates into existing deployment pipelines.

### No Code Sharing Required
The commercial license explicitly guarantees that Customer has no obligation to share modifications, configurations, or data with Licensor. All processing occurs locally, and no data is transmitted externally unless explicitly configured by Customer.
