# Loop-CRM — Database ERD

Entity-relationship diagrams for the Loop-CRM Django models
(`projects/loop-crm/backend/apps/`). Generated by `django-extensions`
`graph_models` — one diagram for the whole Loop-CRM domain plus one per app,
so every **team domain** has its own image: sales (`crm`), marketing,
attribution/RevOps, finance, POS ingestion, SaaS billing, and the core
workspace platform.

## Generate

From `projects/loop-crm/backend/`:

```bash
# Full combined diagram (all Loop-CRM domain apps)
make erd

# One diagram per app → docs/erd/<app>.png
make erd-all
```

The recipe first writes a DOT intermediate (no graphviz required), then renders
PNG with `dot`. `django_extensions` is in `INSTALLED_APPS`
(`backend/configs/default/__init__.py`); the packages come from
`projects/pyproject.toml`.

## Files

| File | Covers (team / domain app) |
|---|---|
| `loop_crm_erd.png` | Combined ERD — every domain app below |
| `core.png` | `apps.core` — Workspace (multi-tenant root), UserProfile, AuditLog, workflows, webhooks, email sync, TaskExecution |
| `crm.png` | `apps.crm` — **sales** pipeline: Company, Contact, Pipeline/Stage, Deal, Activity, custom fields/objects |
| `marketing.png` | `apps.marketing` — Campaign, SocialChannel, Post, PostAnalytics, Media |
| `attribution.png` | `apps.attribution` — AttributionModel, AttributionTouchpoint |
| `finance.png` | `apps.finance` — Invoice, Payment, RevenueEvent |
| `pos.png` | `apps.pos` — Formint POS ledger: PosSale/Item/Payment |
| `billing.png` | `apps.billing` — Plan, BillingAccount, Seat (Stripe SaaS billing) |
| `pages.png` | `apps.pages` — Wagtail landing/builder pages |

> PNG files are generated output — not committed to version control
> (`*.png` is git-ignored). DOT intermediates and this README are the tracked
> contract; regenerate after any model migration with `make erd` or
> `make erd-all`.

## Requirements

- `graphviz` system package — pre-installed in the backend Docker image;
  needed only for PNG rendering
- `django-extensions` + `pydot` Python packages (in `projects/pyproject.toml`)
- `django_extensions` in `INSTALLED_APPS` (`backend/configs/default/__init__.py`)

## Team mapping

| Team / audience | App(s) in the diagrams |
|---|---|
| Sales | `crm` (pipeline, deals, companies, contacts, activities) |
| Marketing | `marketing` (campaigns, channels, posts, analytics) + `attribution` (touchpoints) |
| Finance / RevOps | `finance` + `pos` + `attribution` |
| Platform / engineering | `core` (workspace, RBAC, workflows, webhooks) |
| Product / SaaS | `billing` (plans, seats, Stripe) + `pages` (Wagtail landing) |

Model coverage (as of 2026-09-06): 42 domain models across the Loop-CRM apps;
the combined graph's node set includes every model above.
