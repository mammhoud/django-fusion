# Formint Cloud — Database ERD

Entity-relationship diagrams for the Formint Cloud (POS SaaS) Django models.
Generated by `django-extensions` `graph_models` management command using `pydot` and Graphviz.

## Generate

From `projects/formints/formint-cloud/`:

```bash
# Full combined diagram (all apps)
make erd

# One PNG per app
make erd-all
```

Output is written to this directory (`docs/erd/`).

## Files

| File | Description |
|---|---|
| `formint_cloud_erd.png` | Combined ERD — all registered apps |
| `apps_core.png` | `apps.core` — organizations, branches, tenants, CRM models |
| `apps_domain.png` | `apps.domain` — site and domain sync configuration |
| `apps_handlers.png` | `apps.handlers` — WebSocket consumers and sync handler models |

> PNG files are generated output — not committed to version control.
> Run `make erd` or `make erd-all` to regenerate them locally.

## Requirements

- `graphviz` system package (install with `apt-get install graphviz` in the dev environment)
- `django-extensions` and `pydot` Python packages (in `backend/pyproject.toml`)
- `django_extensions` in `INSTALLED_APPS` (in `backend/configs/__init__.py`)
