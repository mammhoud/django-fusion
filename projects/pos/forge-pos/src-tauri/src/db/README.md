# 📁 POS-KO Database Layer (`src-tauri/src/db/`)

> **Related Names:** `Diesel`, `SQLite`, `schema`, `models`, `migrations`, `connection`, `ORM`
> **Tags:** #rust #database #diesel #sqlite #models #schema

Rust/Diesel database layer: connection management, auto-generated schema, and type-safe model definitions.

```
db/
├── mod.rs              # 🔴 Connection, migrations, path resolution
├── models.rs           # 🔴 29 tables × 3 structs each (Queryable/Insertable/AsChangeset)
└── schema.rs           # 🔴 Diesel table!() definitions (auto-generated)
```

## Customization Tags

| File | Tag | How to customize |
|------|-----|-----------------|
| `mod.rs` | 🔴 `not-customizable` | Connection/path logic is core infrastructure |
| `models.rs` | 🔴 `not-customizable` | Must match schema.rs exactly |
| `schema.rs` | 🔴 `not-customizable` | Auto-generated by `diesel print-schema` |

> ⚠️ **Warning:** Never edit `schema.rs` directly — edit migrations and regenerate via `diesel print-schema > src/db/schema.rs`.

## Key Functions (`mod.rs`)

```rust
pub fn get_db_path(app: &AppHandle) -> Result<PathBuf, String>     // Resolve DB path
pub fn get_db_path_from_env() -> Result<PathBuf, String>            // For seed bin
pub fn open_conn(db_path: &PathBuf) -> Result<SqliteConnection, String>  // Open connection
pub fn run_migrations(db_path: &PathBuf) -> Result<(), String>      // Auto-migrate
pub const MIGRATIONS: EmbeddedMigrations = embed_migrations!("migrations");
```

## Model Pattern

Each table has 3 structs:

| Struct | Derives | Used for |
|--------|---------|----------|
| `<Table>` | `Queryable, Selectable, Serialize, Clone` | Reading rows |
| `New<Table>` | `Insertable, Deserialize` | Creating rows |
| `Update<Table>` | `AsChangeset, Deserialize` | Partial updates |
