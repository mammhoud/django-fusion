Authentication

API Key (Header)

Pass your API key in the X-API-Key header:

curl -H "X-API-Key: YOUR_API_KEY" /api/v1/products/

Device Token (Bearer)

Device tokens from POST /auth/token authenticate per-device:

curl -H "Authorization: Bearer DEVICE_TOKEN" /api/v1/sales/

Pagination

All list endpoints support pagination:

Response includes count, next, previous, and results.
