# Rust / Tauri Docs — POS Full

> **Directory:** `docs/rust/`
> **Language:** Rust (2021 edition)
> **Framework:** Tauri 2.x + Diesel ORM
> **Project:** `projects/pos/pos-full/`

---

## Crate Structure

```
src-tauri/src/
├── db/              # Database models (models.rs, schema.rs)
├── commands/        # Tauri invoke handlers
├── migrations/      # Diesel SQL migrations
└── main.rs          # Entry point
```

## Diesel Conventions

- Queryable structs in `models.rs`
- Schema generated by `diesel print-schema`
- Migrations in `src-tauri/migrations/YYYY-MM-DD-HHMMSS_description/`

## Tauri Commands

```rust
#[tauri::command]
fn my_command(arg: String) -> Result<String, String> {
    // Database operations
    Ok("result".to_string())
}
```

Register in `main.rs`:
```rust
.invoke_handler(tauri::generate_handler![my_command])
```

See `../PROMPTS.md#rust--tauri-prompts` for code generation templates.
