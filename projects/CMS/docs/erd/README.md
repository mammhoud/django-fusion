# Syntara — Database ERD

Entity-relationship diagrams for the Syntara (Cypercloud AI chat) Django models.
Generated by `django-extensions` `graph_models` management command using `pydot` and Graphviz.

## Generate

From `projects/syntara/`:

```bash
# Full combined diagram (all apps)
make erd

# One PNG per app
make erd-all
```

Output is written to this directory (`docs/erd/`).

## Files

| File | Description |
|---|---|
| `syntara_erd.png` | Combined ERD — all registered apps |
| `chat.png` | `chat` — conversation and message persistence models |

> PNG files are generated output — not committed to version control.
> Run `make erd` or `make erd-all` to regenerate them locally.

## Requirements

- `graphviz` system package (already in the Syntara Docker image)
- `django-extensions` and `pydot` Python packages (in `requirements.txt`)
- `django_extensions` in `INSTALLED_APPS` (in `settings.py`)
