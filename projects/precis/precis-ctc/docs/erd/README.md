# CTC Research — Database ERD

Entity-relationship diagrams for the CTC Research (precis-ctc) Django models.
Generated by `django-extensions` `graph_models` management command using `pydot` and Graphviz.

## Generate

From `projects/precis/precis-ctc/backend/`:

```bash
# Full combined diagram (all apps)
make erd

# One PNG per app
make erd-all
```

Output is written to this directory (`docs/erd/`).

## Files

| File | Description |
|---|---|
| `precis_ctc_erd.png` | Combined ERD — all registered apps |
| `apps_content.png` | `apps.content` — Wagtail content hooks and tasks |
| `apps_learning.png` | `apps.learning` — courses, catalog, enrollment, progress |
| `apps_pages.png` | `apps.pages` — page and domain feature models |
| `apps_handlers.png` | `apps.handlers` — request handler and signal models |
| `apps_auth.png` | `apps.auth` — allauth adapter models |
| `apps_core.png` | `apps.core` — shared routes and service primitives |
| `apps_domain.png` | `apps.domain` — site and domain configuration |

> PNG files are generated output — not committed to version control.
> Run `make erd` or `make erd-all` to regenerate them locally.

## Requirements

- `graphviz` system package (already in the backend Docker image)
- `django-extensions` and `pydot` Python packages (in `projects/pyproject.toml`)
- `django_extensions` in `INSTALLED_APPS` (via `configs/base/apps.py`)
