# Precis Main — Database ERD

Entity-relationship diagrams for the Precis Main (unified LMS + landing) Django models.
Generated by `django-extensions` `graph_models` management command using `pydot` and Graphviz.

## Generate

From `projects/precis/precis-main/backend/`:

```bash
# Full combined diagram (all apps)
make erd

# One PNG per app
make erd-all
```

Output is written to this directory (`docs/erd/`).

## Files

| File | Description |
|---|---|
| `precis_main_erd.png` | Combined ERD — all registered apps |
| `apps_content.png` | `apps.content` — StreamField blocks and content models |
| `apps_pages.png` | `apps.pages` — Wagtail page models |
| `apps_handlers.png` | `apps.handlers` — request handler models |
| `apps_auth.png` | `apps.auth` — authentication models |
| `apps_learning.png` | `apps.learning` — LMS catalog, enrollment, progress |
| `apps_tasks.png` | `apps.tasks` — background task execution |
| `apps_components.png` | `apps.components` — shared component models |
| `apps_domain.png` | `apps.domain` — domain and site configuration |

> PNG files are generated output — not committed to version control.
> Run `make erd` or `make erd-all` to regenerate them locally.

## Requirements

- `graphviz` system package (already in the backend Docker image)
- `django-extensions` and `pydot` Python packages (in `projects/pyproject.toml`)
- `django_extensions` in `INSTALLED_APPS` (via `configs/base/apps.py`)
