## Starting a New Spec

To start a new spec:
1. Create a new directory in this folder
2. Add `requirements.md`, `design.md`, `tasks.md`, and `.config.kiro`
3. Move the spec to `in-progress/` when work begins

## Requirements

Each pending spec should have:
- `requirements.md` - Requirements defined
- `design.md` - Technical design
- `tasks.md` - Implementation tasks
- `.config.kiro` - Spec configuration
