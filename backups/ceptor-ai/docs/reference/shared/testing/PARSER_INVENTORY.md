1. **No custom parsers in project apps** (`ctc-research.com/apps/`, `structa.cloud/apps/`): The `parse_csv` functions found in management commands are simple inline CSV parsing, not reusable parser classes.

2. **SpecParser duplication**: `SpecParser` exists identically in both `crafts_ai` and `nawaai`. The canonical location should be `nawaai` (pure Python). The `crafts_ai` copy should import from `nawaai`.

3. **Schemas are not parsers**: The 111 Ninja/Pydantic schemas are data validation schemas, not string parsers. They do not require round-trip testing per Requirement 18.

4. **`BaseAdapter.serialize_data` / `deserialize_data`**: This pair already implements a round-trip. A property test verifying `deserialize_data(serialize_data(x)) == x` is appropriate.
