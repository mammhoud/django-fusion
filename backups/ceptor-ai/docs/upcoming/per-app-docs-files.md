# Per-App Documentation Files

Status: Planned

Summary: Spec for rolling out `AGENTS.md`, `PROMPTS.md`, and `README.md` files to every app and shared directory in the monorepo that currently lacks them. Defines the canonical structure for each file type, the required sections, and the validation process (link checking, extras checking) to keep them consistent over time.

## What Will Replace This Page
- Full inventory of all apps showing current coverage status
- Copy-paste templates for each file type with section headings
- CI validation pipeline to enforce AGENTS.md/PROMPTS.md standards
- Per-app examples showing site-specific content that follows the shared template
