# Blog & Projects App (VResume)

Status: Planned

Summary: Spec for adding a full blog and projects/portfolio application to the VResume site. This includes Wagtail Page models for blog posts and project showcases, FragmentComponent-based HTMX navigation for post/project detail views, category/tag filtering, and integration with VResume's existing tab-based layout.

## What Will Replace This Page
- Complete CRUD workflows for BlogPage and PortfolioPage models
- HTMX fragment patterns for blog post listings and project galleries
- Template resolution order specific to VResume's www/pages/ structure
- Social sharing and SEO metadata integration
